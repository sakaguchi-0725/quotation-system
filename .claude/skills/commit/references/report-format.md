# 完了報告フォーマット

コミット作成後、ユーザーに以下のフォーマットで報告する。本文やハッシュ、変更ファイル一覧は載せず、作成したコミットのメッセージ(`<type>(<scope>): <件名>`)だけを列挙する。

```
コミットを作成しました。

- <type>(<scope>): <件名>
- <type>(<scope>): <件名>

pushしますか？
```

## 記載ルール

- 列挙するのは各コミットの件名行(`<type>(<scope>): <件名>`)のみ。本文は載せない
- 複数コミットに分割した場合は、作成した順にすべて列挙する
- コミットを作成しなかった場合(diffが空、ユーザーが中断した等)は、その旨と理由を1〜2文で報告する

## 最後に必ず確認すること

報告の直後に、リモートへ push するかどうかをユーザーに質問する。ユーザーの明示的な回答なしに push は実行しない。
