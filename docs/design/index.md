# ユビキタス言語

| 用語 | 意味 |
|---|---|
| 取引先 (Partner) | 見積もり提出先の顧客企業 |
| 商談 (Opportunity) | 取引先からの引き合いを起点に管理する交渉単位 |
| 見積もり (Quote) | 商談に紐づく見積書の1バージョン |
| 見積もり方式 (Estimation Method) | 見積金額の算出方法。ボトムアップ法とファンクションポイント法の2種類から選択する |
| ボトムアップ法 | 見積もり方式の一種。見積明細（単価・数量）を積み上げて見積金額を算出する方法 |
| ファンクションポイント法（FP法） | 見積もり方式の一種。システムの機能規模を機能点数として算出し、そこから工数・金額を導出する方法 |
| 機能項目 (Function Point Item) | FP法において、機能種別・複雑度ごとに数えるシステムの機能単位 |
| 機能種別 (Function Type) | 機能項目の分類。外部入力(EI)・外部出力(EO)・外部照会(EQ)・内部論理ファイル(ILF)・外部インターフェースファイル(EIF)の5種 |
| 複雑度 (Complexity) | 機能項目の複雑さの度合い。低・中・高の3段階 |
| GSC（一般システム特性） | FP法において、システムの技術的な難易度を評価する項目群。性能要件・オンライン更新など6項目で評価する |
| GSC評価 (GSC Score) | GSCの各項目に付与する0〜5点の評価点。合計点から見積金額の補正係数を算出する |
| 生産性係数 (Productivity Rate) | FP法において、機能点数を工数に変換するための係数 |
| 人月単価 (Monthly Rate) | 工数を金額に変換するための、技術者1人月あたりの単価 |
| 見積もり単価設定 (Estimation Settings) | 人月単価・生産性係数を会社共通のマスタ値として保持する設定 |
| 見積明細 (Quote Line) | 単価・数量・条件からなる見積もりの内訳行（ボトムアップ法） |
| 見積金額 (Quote Amount) | 見積もり方式に応じて見積明細またはファンクションポイント見積から自動算出される金額 |
| バージョン (Version) | 見積もりの改版履歴を識別する番号 |
| 商談ステータス (Opportunity Status) | 商談の進行状態を表す区分 |
| 未作成 (Not Created) | 商談ステータスの一種。この商談に対して一度も見積もりを送付していない |
| 提示中（回答待ち） (Quoted) | 商談ステータスの一種。最新の見積もりを取引先に送付済み、回答待ち（修正依頼を受けて改訂中の場合も含む） |
| 受注 (Won) | 商談ステータスの一種。取引先が見積もりを承諾した |
| 失注 (Lost) | 商談ステータスの一種。取引先が見積もりを見送った |
| 営業担当者 (SalesRep) | 取引先・商談・見積もりを操作する唯一のアクター |
| 引き合い | 取引先からの見積もり依頼の起点 |
| 督促 | 回答待ち期間超過時に営業担当者が行う連絡 |
| 承諾 | 取引先が見積もりを受諾する回答 |
| 見送り | 取引先が見積もりを受け入れない回答 |
| 修正依頼 | 取引先が見積もり内容の修正を求める回答 |
